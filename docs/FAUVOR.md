# FAUVOR Gaming

## Rol dentro del catálogo

Catálogo educativo de videojuegos.

Interfaz React y Vite para explorar videojuegos, administrar el catálogo y utilizar una lista de deseos. Se conserva la naturaleza educativa y la simulación de operaciones.

## Identidad

El nombre visible del producto es **FAUVOR Gaming**. Se conserva la URL `Franc-Devel/Francis-Gamer` para mantener los enlaces históricos. El símbolo y los iconos provienen del kit original FAUVOR. La paleta utiliza marfil, blanco cálido, bronce y dorado; los estados positivos usan un oliva sobrio.

Las portadas son ilustraciones conceptuales, no capturas de pantalla. No acreditan clientes, cifras de uso, resultados comerciales ni funciones que no estén implementadas.

## Ejecución

`npm ci`, `npm run dev` y `npm run build`.

## Alcance y límites

No se convierte en una tienda con cobros reales. La identidad FAUVOR no implica propiedad ni afiliación con los videojuegos ilustrados. Se conservan los créditos académicos y las contribuciones originales.

FAUVOR Flow es un proyecto independiente. No conecta automáticamente estas bases o servicios: cualquier integración futura debe implementarse y verificarse.
